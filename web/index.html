Observed-data relative support

Wald Likelihood Support

Explore how much relative support an observed estimate and reported 95% confidence interval provide for candidate effect sizes under a one-parameter Wald reconstruction.

This educational research tool shows normalized, approximate relative likelihood. It does not recover the original fitted-model likelihood, assign probabilities of truth, validate clinical thresholds, or provide clinical decision support.

Observed estimate and interval

Supply a published two-sided 95% confidence interval. The point estimate is optional because the interval midpoint determines the reconstructed estimate on the working scale.

Check the inputs

    Defaults to 1 for ratios and 0 for additive effects.

    Separate values with commas or spaces. These are user-supplied reference markers, not validated clinical or decision thresholds.

    S−2 uses a log-support cutoff of −2. A 2:1 interval is a different, narrower criterion.

    Optional candidate A versus candidate B

    Supply both candidates. Results are reported explicitly in the order L(A)/L(B), with the finite log ratio retained if the ordinary ratio cannot be represented.

    A plausible display range changes only the plotted and exported grid, never the reconstructed support summaries or interval.

      Exports

      CSV contains only the five plotted grid fields. Interval and pairwise results remain in the accessible tables and strict JSON response.

      When the local runtime is ready, update the support curve to populate the plot, reconstructed summary, support tables, caption, and exports.

      Relative likelihood is normalized to 1 at the CI-implied estimate. It is not a posterior probability that a candidate value is true.

      Interpretation and scope

      This is an approximate profile-likelihood-style view under Wald assumptions, not the original fitted-model profile likelihood. Support ratios do not become probabilities of truth.
